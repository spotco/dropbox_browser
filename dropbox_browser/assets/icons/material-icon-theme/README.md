# Material Icon Theme Assets

Selected SVG icons vendored from Material Icon Theme for VS Code, plus the
app-specific `box-favicon.svg`.

Upstream: https://github.com/material-extensions/vscode-material-icon-theme
License: MIT, included in `LICENSE`.

These assets are used for file/folder icon rendering and the browser favicon.

Notes for later mapping:

- Archive extensions such as `.zip`, `.rar`, `.7z`, `.tar`, `.gz`, and `.bz2`
  should use `zip.svg`; this set does not include distinct RAR/7z icons.
- Windows executables can use `exe.svg`; DLLs can use `dll.svg`; installers can
  use `installation.svg` where useful.
